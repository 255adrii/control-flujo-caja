Aficciones

He trabajado en diversos proyectos de desarrollo web orientados tanto a la funcionalidad como a la experiencia de usuario. Entre ellos destaca TaskFlow, una aplicación web de gestión de tareas desarrollada con React y Node.js, pensada para equipos pequeños que necesitan organizar proyectos de forma colaborativa. En este proyecto implementé autenticación con JWT, bases de datos en MongoDB y un diseño responsive basado en Material UI.
